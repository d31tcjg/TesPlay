# Tested vehicles

The maintainer has tested TesPlay on the following vehicles and reports that all work without issues.

| Vehicle | Model year | Infotainment processor | Result |
| --- | --- | --- | --- |
| Model 3 Long Range | 2019 | Intel | Working without issues |
| Model 3 Long Range | 2021 | Intel | Working without issues |
| Model 3 Long Range | 2023 | AMD | Working without issues |
| Model Y Long Range | 2023 | AMD | Working without issues |
| Model 3 Performance | 2026 | AMD | Working without issues |
| Model Y Performance | 2026 | AMD | Working without issues |

These are the only vehicle configurations tested by the maintainer. Firmware versions and separate front/rear-screen coverage were not recorded. Other configurations and future firmware may behave differently. Raspberry Pi host hardware has not been verified.

Always use TesPlay while safely parked with the vehicle in Park. To report another configuration or a reproducible problem, use [GitHub Issues](https://github.com/rdvnit/TesPlay/issues) and include the TesPlay version, model year, processor and firmware version if available. Do not include a VIN, registration plate, location or account credentials.
