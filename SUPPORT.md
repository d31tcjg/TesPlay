# Community reports

TesPlay was built and is maintained by **rdvnit**, a single developer. There is no dedicated support service, help desk or guaranteed response time.

Report reproducible bugs through [GitHub Issues](https://github.com/rdvnit/TesPlay/issues). Community reports help identify problems the maintainer can investigate and fix when time permits. A report does not guarantee a fix or a delivery date.

Before opening an issue, check the [user guide](docs/usage.md), [deployment guide](docs/deployment.md), [known limits](docs/reference-audit.md) and existing issues.

Include the TesPlay version, relevant host/browser or vehicle configuration, steps to reproduce, expected result and actual result. For vehicle issues, include firmware and processor if known. Sanitized logs and screenshots can help.

Never post passwords, provider URLs containing credentials, API tokens, OAuth secrets, databases, encryption keys, environment files, VINs or personal media information. Remove sign-in and pairing QR codes from screenshots. For a security issue, describe the problem without posting secrets or personal data.

The maintainer does not provide media, IPTV accounts, playlists or help obtaining unauthorized content.
